LEPOT SHOP V2 — Bothost

ФАЙЛЫ
- server.py — сайт, API, прямой приём файлов на сервер и выдача защищённых ссылок.
- bot.py — Telegram-бот, профиль, заказы, подтверждение, отзывы и админ-команды.
- index.html — чёрно-белая витрина.
- upload.html — закрытая панель загрузки товаров.
- config.py — чтение Token.env (переменные Bothost имеют приоритет).
- Icon.png — иконка сайта.
- media/ — постоянное хранилище обложек и материалов.
- Token.env — сохранённый файл конфигурации; не публикуйте его в открытом GitHub.

BOTHOST
Главный файл: server.py
Порт: 3000
Python: 3.11+
Зависимости: requirements.txt

Переменные окружения Bothost:
BOT_TOKEN=токен бота
ADMIN_IDS=ваш_telegram_id
BOT_USERNAME=username_бота_без_@
MANAGER_USERNAME=GifterBroPro
SITE_URL=https://lepotshop.bothost.tech
PORT=3000

Если эти значения уже находятся в Token.env, config.py прочитает их автоматически. Переменные панели Bothost имеют приоритет над Token.env. BOT_TOKEN не выводится в логи.

ПЕРВЫЙ ЗАПУСК
1. Загрузите содержимое папки проекта в GitHub-репозиторий.
2. В Bothost выберите этот репозиторий и главный файл server.py, порт 3000.
3. Проверьте переменные BOT_TOKEN, ADMIN_IDS, BOT_USERNAME, SITE_URL и MANAGER_USERNAME.
4. В BotFather настройте домен сайта для Telegram Login Widget: /setdomain и укажите lepotshop.bothost.tech.
5. Откройте бота и отправьте /start. Пользователь создаёт профиль: язык → фото (можно пропустить) → имя.
6. Администратор отправляет /admin. Бот выдаст защищённую ссылку на панель загрузки, действующую 1 час.

СОЗДАНИЕ ТОВАРА
В панели /admin-upload заполните название, описание, цену, обложку и выберите один или несколько файлов любого типа. Файлы передаются напрямую на HTTP-сервер Bothost потоками по 1 МБ, не скачиваются через Telegram Bot API. После завершения нажмите «Создать товар и загрузить файлы».

Размер файлов
В коде нет фиксированного лимита в 20 МБ: это ограничение обычного облачного Telegram Bot API на скачивание файлов ботом. Прямая загрузка через сайт обходит именно это ограничение. Фактический максимальный размер зависит от свободного места на диске Bothost, ограничений тарифа/прокси и тайм-аутов хостинга. Поэтому обещать конкретное число МБ без данных о квоте Bothost нельзя. Проверяйте свободное место и не загружайте больше, чем позволяет тариф.

ПОКУПКА И ВЫДАЧА
- При нажатии «Купить» сайт показывает загрузку и отправляет заказ в Telegram, не перенаправляя пользователя на start-ссылку.
- Бот отправляет сведения о заказе, инструкцию оплаты и кнопку менеджера @GifterBroPro.
- После нажатия «Я оплатил» администраторы получают запрос на подтверждение.
- Бесплатные товары выдаются отдельной кнопкой.
- После подтверждения бот отправляет защищённые ссылки на скачивание материалов. Это позволяет выдавать файлы, которые слишком велики для отправки самим Telegram-ботом.
- Ссылки на скачивание действуют 7 дней.
- После выдачи бот предлагает оставить отзыв; отзывы и аватары подтверждённых покупателей отображаются у товара.

КОМАНДЫ
/start — регистрация и меню
/admin — защищённая панель создания товаров (только ADMIN_IDS)
/setpayment текст — изменить текст инструкции по оплате
/review НОМЕР_ЗАКАЗА — оставить отзыв после получения заказа

ВАЖНО
- Не добавляйте Token.env в публичный репозиторий. Если токен когда-либо публиковался, отзовите его через @BotFather и задайте новый в Bothost.
- database.db и media/ должны храниться на постоянном диске. Не удаляйте их при обновлении кода.
- Для Telegram Login Widget домен должен быть подтверждён в BotFather.
- Размер загрузки также может ограничиваться настройками reverse proxy/платформы Bothost, которые приложение не может отменить.
- Telegram может ограничивать размер файлов, которые бот отправляет непосредственно сообщением. В этой версии материалы выдаются ссылками с сайта, поэтому отправка больших файлов через Telegram не требуется.
/products — список товаров
/hideproduct ID — скрыть товар с витрины, не удаляя историю заказов
/showproduct ID — вернуть товар на витрину
