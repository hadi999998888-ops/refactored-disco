LEPOT SHOP — запуск на Bothost

Файлы:
- server.py — HTTP-сервер, запускает bot.py в отдельном потоке.
- bot.py — Telegram-бот и админ-команды.
- index.html — витрина.
- requirements.txt — зависимости.
- media/ — загруженные обложки и видео.

Bothost:
Главный файл: server.py
Порт: 3000
Переменные окружения:
BOT_TOKEN=НОВЫЙ_ТОКЕН_ОТ_BOTFATHER
ADMIN_IDS=ВАШ_TELEGRAM_ID
BOT_USERNAME=username_бота_без_@
MANAGER_USERNAME=username_менеджера_без_@
SITE_URL=https://ваш-домен-bothost
STARS_ENABLED=false
PORT=3000

Не публикуйте токен в GitHub. Токен, ранее отправленный в чат, необходимо отозвать через @BotFather (/revoke) и заменить новым.

Админ-команды:
 /admin — справка
 /addproduct — добавить товар (название, описание, число видео, цена, XTR/GIFTS, обложка, видео)
 /products — список товаров
 /stats — статистика

Важные ограничения текущей версии:
- Ручная оплата подтверждается администратором в боте.
- GIFTS — ручная оплата через менеджера; бот не может автоматически проверить факт отправки подарка.
- XTR пока отображается как тип цены, но полноценный автоматический Stars invoice в этой сборке не реализован. Не включайте STARS_ENABLED=true до добавления и тестирования платежного сценария.
- При подтверждении бот отправляет загруженные видео пользователю.
- Если отправка части видео не удалась, проверьте заказ вручную, прежде чем повторно предпринимать действия.
- Для надёжной работы держите database.db и media/ на постоянном диске.
- Установите актуальный username бота и менеджера в переменных Bothost.
